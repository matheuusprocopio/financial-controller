## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Teste de Autenticação Firebase

Para testar a autenticação Firebase integrada com o backend:

1. Certifique-se de que o backend está rodando em `http://localhost:8080`
2. Acesse: [http://localhost:3000/test-auth](http://localhost:3000/test-auth)
3. Faça login no Firebase (email/senha ou Google)
4. Teste o login no backend usando o token obtido

**Nota:** Configure a variável de ambiente `NEXT_PUBLIC_API_URL` se o backend estiver em uma URL diferente de `http://localhost:8080`.
